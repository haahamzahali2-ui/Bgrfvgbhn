☁️ Google Sheet backup Not connected

Every save also goes to your own Google Sheet, so nothing is lost if your browser is cleared — and it works on any device.

·

How to set it up (5 minutes, one time)
  1. Go to sheets.new to make a new Google Sheet.
  2. In the Sheet: Extensions → Apps Script. Delete what's there, paste the script, and click Save.
  3. Deploy → New deployment → ⚙️ Web app. Execute as Me, access Anyone → Deploy.
  4. Allow access: Advanced → Go to (project) → Allow. ("Unverified" just means it's your own script.)
  5. Copy the Web app URL, paste it above, and click Connect.

On another device, paste the same URL there. Keep the URL private — anyone with it can see your data.
